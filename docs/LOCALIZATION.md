# Локализация: состояние и что осталось

Обновлено: 2026-11-09, версия **1.14.0**.

## Готово

- Экран первого запуска `LanguageActivity`: **English выбран по умолчанию**,
  вторым — Русский. Выбор хранится в преф `lang`.
- Вкладка **⚙ → Языки** — первая в настройках; переключение перезагружает
  страницу.
- Страница: `assets/app/i18n.js` — словарь RU→EN, правила для чисел/единиц/дат,
  автоматический перевод текстовых узлов и `title`/`placeholder`/`aria-label`.
- **Динамические подписи чата** (`#msgs`) переводятся через `T()`: статусы
  инструментов, «Размышления», «запрос/результат», «Показать раньше»,
  «копировать», пустые состояния. `T()`/`__t` теперь **не трогают строки,
  когда язык русский** — раньше русские пользователи видели английские
  подписи в чате.
- Длинные фразы переводятся как подстроки (`LONG` в `i18n.js` и `Lang.tr`),
  поэтому склеенные из кусков тексты (заметки, инструкции, отчёты) больше не
  остаются наполовину русскими.
- Пользовательские данные помечены `data-noi18n`: названия чатов, имена
  файлов и папок, пути, названия моделей. Они не переводятся.
- Нативные экраны: `Lang.java` — карта строк + `localizeView`; переведены
  онбординг, настройки, разрешения, уведомления, splash, диалоги и тосты
  (`SettingsActivity`, `AppUpdater`, `RuntimeService`, `Notifications`,
  `MainActivity`, `Updater`).
- Даты в статистике использования форматируются по языку (`en-US`/`ru-RU`).
- Исправлены остатки старого ПК-моста: «OpenCode Remote» → «OpenCode»,
  «загрузится на компьютер» → «прикрепится к сообщению», «удалится с
  компьютера» → «с телефона», устаревшие «обновите до 1.5»/«нужно 1.4».
- Исправлен латентный краш `t is not a function`, из-за которого чат с
  вложением без имени мог не загрузиться.

## Проверено на телефоне (VKP-NX9, Android 16)

- Чистая установка и первый экран: English выбран, Русский вторым.
- Переключение en↔ru, перезапуск приложения, нативные настройки и онбординг.
- В English пройдены: чат с инструментами/размышлениями/asks, вложения,
  модель, файловый проводник и быстрые папки, настройки (все вкладки),
  разрешения, Shizuku-инструкция, провайдеры (каталог, карточка, OAuth-тексты),
  веб-поиск, использование/тарифы, обновление приложения, диалоги и тосты.
- Поиск кириллицы в UI: пользовательских путей/названий не считаем.
- Русский интерфейс после всех правок остаётся исходным.

## Как добавить язык (технически)

1. `assets/app/page.html`: `LANGUAGES = [{code:"en",...},{code:"ru",...}, ...]`.
2. `assets/app/i18n.js`: `EN` — пример; для нового языка сделать `ES`/`DE` и
   выбирать словарь по `OCLang.code` (сейчас `tr()` использует только `EN`).
3. `Lang.java`: `get()` уже поддерживает любое значение; `tr()`/`EN_MAP`
   расширить или сделать `Map<String, Map<String,String>>`.
4. `LanguageActivity`: добавить RadioButton.
5. Пересобрать, проверить переключение и отсутствие русских строк.

Ориентир: 2–4 часа на язык после того, как английский закрыт на 100%.
