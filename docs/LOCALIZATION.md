# Локализация: состояние и что осталось

Обновлено: 2026-11-10, версия **1.22.0**.

## Готово

- Экран первого запуска `LanguageActivity`: **English выбран по умолчанию**,
  затем Русский, **中文（简体）**, **中文（繁體）**, **Español**,
  **Português (Brasil)**, **Deutsch** и **Français**. Выбор хранится в преф
  `lang`.
- Вкладка **⚙ → Языки** — первая в настройках; переключение перезагружает
  страницу.
- Языки: `en`, `ru`, `zh` (упрощённый китайский), `zh-Hant` (традиционный,
  тайваньские термины), `es` (испанский), `pt` (португальский, Бразилия),
  `de` (немецкий), `fr` (французский). В списке языков — флаги стран.
- Страница: `assets/app/i18n.js` — словарь RU→EN и правила; отдельные
  `i18n-zh.js` (RU→ZH), `i18n-zh-hant.js` (RU→ZH-Hant через OpenCC s2twp),
  `i18n-es.js` (RU→ES), `i18n-pt.js` (RU→PT-BR), `i18n-de.js` (RU→DE) и
  `i18n-fr.js` (RU→FR) — по ≈565 строк и подстановки.
  Автоматический перевод текстовых узлов и `title`/`placeholder`/`aria-label`.
- **Динамические подписи чата** (`#msgs`) переводятся через `T()`: статусы
  инструментов, «Размышления», «запрос/результат», «Показать раньше»,
  «копировать», пустые состояния. `T()`/`__t` не трогают строки, когда язык
  русский.
- Длинные фразы переводятся как подстроки (`LONG` для EN/ZH/ES/PT), поэтому
  склеенные из кусков тексты не остаются наполовину русскими.
- Пользовательские данные помечены `data-noi18n`: названия чатов, имена
  файлов и папок, пути, названия моделей. Они не переводятся.
- Нативные экраны: `Lang.java` + `LangZh.java` + `LangZhHant.java` +
  `LangEs.java` + `LangPt.java` + `LangDe.java` + `LangFr.java`,
  `Lang.localizeView`;
  переведены онбординг, настройки, разрешения, уведомления, splash, диалоги и
  тосты (`SettingsActivity`, `AppUpdater`, `RuntimeService`, `Notifications`,
  `MainActivity`, `Updater`).
- Даты в статистике: `en-US` / `ru-RU` / `zh-CN` / `zh-TW` / `es-ES` /
  `pt-BR` / `de-DE` / `fr-FR`.
- Исправлены остатки старого ПК-моста и латентный краш `t is not a function`.

## Как добавить язык (технически)

1. `assets/app/page.html`: добавить код в `LANGUAGES`.
2. Создать `assets/app/i18n-xx.js` (`window.OC_XX` + `OC_XX_SUBS`) и
   подключить его **до** `i18n.js`; в `i18n.js` добавить словарь в `tr()`.
3. Добавить `LangXx.java` по образцу `LangZh.java` и ветку в `Lang.tr()`,
   `Lang.t()`, `Lang.languageName()`.
4. `LanguageActivity`: добавить RadioButton и обработку кода.
5. Пересобрать, проверить переключение и отсутствие русских строк.

Ориентир: 2–4 часа на язык после того, как английский закрыт на 100%.
