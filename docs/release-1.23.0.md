# OpenCode Android 1.23.0

## New

- The update arrow is now a **separate button** to the right of the settings gear in the side menu — the same 34 px size, with the same soft yellow glow when an update is available.
- **An update banner appears at the very top of Settings** whenever a new version exists, above the tabs. One tap opens the update sheet — no more hunting through nested screens.
- The banner is only shown when an update is actually available and disappears in other sheets.

## Notes

- Verified on a phone: button placement, banner visibility, opening the update sheet and the existing download/install flow.
- Updates keep chats, settings and credentials. The APK is checked by SHA-256 and by the signing certificate before installation.

Стрелка обновления в боковом меню стала **отдельной кнопкой справа от шестерёнки** того же размера (34 px) с мягким жёлтым свечением. В настройках при наличии обновления **в самом верху, над вкладками**, появляется баннер «Доступно обновление» — одно нажатие открывает экран обновления. Баннер показывается только когда обновление действительно есть. Проверено на телефоне; обновление сохраняет чаты, настройки и ключи.
