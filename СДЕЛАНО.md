Сделать **самостоятельное Android-приложение**, которое работает как OpenCode,

## Что выяснилось

- Старое приложение — это WebView + `oc_server.py` на ПК; без ПК оно не работает.
- `rea-main` в рабочей папке — это **REA (reverse engineering)**, к OpenCode
  отношения не имеет. В проекте не используется.
- Установленный OpenCode — **v2.2.6** (Electron desktop + `opencode-cli.exe`).
- Исходники OpenCode: GitHub `anomalyco/opencode`, ветка `dev`
  (склонированы в `%TEMP%\opencode-src` для изучения API).
- **Главный результат проверки:** официальный `opencode-linux-arm64-musl`
  **запускается на Android 16 напрямую** через musl loader. Полный сервер
  `opencode serve` работает, модели отвечают, инструменты `write`/`shell`/`glob`
  выполняются на телефоне.
- Поэтому тяжёлый Debian + proot **не нужен**. Приложение использует нативный
  бинарник OpenCode + musl-библиотеки внутри APK.

## Архитектура (кратко)

```
WebView (page.html + bridge.js)
   → локальный HTTP 127.0.0.1:8769 (Kotlin)
      → /oc/*  → opencode serve 127.0.0.1:4096 (Basic auth)
      → /android/* → файлы телефона
      → /upload, /files, /thumb
```

- `opencode serve` запускается foreground-сервисом `RuntimeService`.
- `bridge.js` повторяет протокол `oc_server.py` (`state`, `upd`, `chats`,
  `models`, `fs`, `asks`, …), но работает напрямую с OpenCode.
- ПК не участвует вообще.

## Что реализовано

### Рантайм
- OpenCode 2.2.6 arm64 musl + musl loader + libstdc++/libgcc.
- ripgrep 15.1.0 (musl) + libpcre2 — для инструментов `grep`/`glob`.
- Распаковка из APK при первом запуске (~2 секунды), маркер версии.
- `shell: /system/bin/sh` (Android shell), `PATH` с `files/usr/bin`.
- `OPENCODE_DISABLE_FFF=1` — чтобы не грузить glibc-модуль и использовать rg.
- PID-файл и очистка осиротевших процессов; свободный порт 4096+.

### Android-приложение
- Пакет `ru.opencode.android`, minSdk 26, targetSdk 28 (как Termux — разрешает
  запуск своих бинарников из каталога приложения).
- WebView со страницей из `assets/app`, тёмный splash, автозапуск сервиса.
- Foreground-сервис + уведомление, автозапуск после перезагрузки (`BootReceiver`).
- `LocalServer`: страница, прокси `/oc`, `/android/fs`, `/android/mkdir`,
  `/android/home`, `/android/config`, `/upload` (multipart), `/files`, `/thumb`.
- `AndroidBridge`: уведомления, вибрация, копирование, открытие ссылок,
  системные настройки, выбор файла, проверка прав.
- `SettingsActivity`: рабочая папка, права на файлы, отключение оптимизации
  батареи, перезапуск, журнал, тест уведомления (ключ Zen — во вкладке «Провайдеры»).
- Токен `X-Bridge-Token` для всех чувствительных маршрутов (без него 403).
- Фоновые уведомления «Ответ готов» / «OpenCode ждёт ответа» (нативный watcher).

### Интерфейс (дизайн из старого приложения)
- `page.html` — копия `page_chat.html` с минимальными правками:
  - вместо WebSocket — `bridge.js`;
  - кнопка «панель ПК» стала шестерёнкой настроек;
  - кнопка установки APK с ПК скрыта;
  - выбор папки стартует с рабочей папки телефона;
  - ключ OpenCode Zen и вход по аккаунту — во вкладке «Провайдеры»;
  - медиа-пути понимают Android (`/storage/...`), а не только `C:\...`.
- Модель по умолчанию — `deepseek-v4.1-flash-free` (OpenCode Zen, бесплатная);
  выбор запоминается.
- Работают: чаты, переименование, удаление, выбор модели, стриминг,
  размышления, инструменты, вложения, папки, галерея, настройки.

## Как установить/пользоваться

1. Взять `OpenCodeAndroid.apk` из папки проекта.
2. Установить на телефон (разрешить установку из этого источника).
   Если `INSTALL_FAILED_VERIFICATION_FAILURE`:
   ```powershell
   adb shell settings put global verifier_verify_adb_installs 0
   adb shell settings put global package_verifier_enable 0
   adb install --no-incremental -r -d OpenCodeAndroid.apk
   ```
3. Открыть **OpenCode**. Первый запуск: разрешить доступ к файлам
   (и при желании — отключить оптимизацию батареи в настройках).
4. Рабочая папка по умолчанию: `/storage/emulated/0/OpenCode`.
5. Модель: кнопка с названием модели внизу. Бесплатные модели OpenCode Zen
   работают без ключа. Ключ (если нужен платный) — шестерёнка → «Провайдеры» →
   «Ключ OpenCode Zen».
